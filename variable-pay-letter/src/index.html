How this works
  1. Set the letter date. Every letter in the batch carries this date.
  2. Paste your two columns into the table. Copy Employee ID and Variable Pay straight out of your spreadsheet and paste anywhere in the grid. Rows are added as needed, and a copied header row is ignored, so selecting the headings too is fine.
  3. Check the Status column. Each row shows the employee it matched and the amount. Rows highlighted in red need fixing — the zip stays locked until every row is clean, so nobody is quietly left out of the run.
  4. Download. Preview or Download on a row handles that one letter. Download all Letters (Zip) at the bottom builds the whole batch.
