How this works
  1. Set the letter date. The date printed on every letter in the batch. The effective date is separate and set per employee.
  2. Paste your columns into the table. Employee ID, Fixed CTC, Variable Pay, Effective From, and Revised Designation if it is a promotion. Rows are added as needed and a copied header row is ignored. Leave Variable Pay blank, or zero, for anyone on a fixed-only package — their letter states one figure instead of a bifurcation.
  3. Check the Status column. Each row shows the revised CTC, its split where there is one, and the date it takes effect. Rows in red need fixing — the zip stays locked until every row is clean.
  4. Download. Preview or Download on a row handles that one letter. Download all Increment Letters (Zip) builds the whole batch.
